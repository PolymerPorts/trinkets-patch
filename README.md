# Polymer Patch for Trinkets Updated
This is a patch for [Trinkets Updated](https://modrinth.com/mod/trinkets-updated),
making it work fully server side, with most of its functionality intact.
Do note things such as Elytra or other physics altering items might not work correctly
and trinkets won't be rendered visually.

Trinkets Updated is required and not included within this mod.

This mod supports server resource pack, about which setup you can read here: https://polymer.pb4.eu/latest/user/resource-pack-hosting/

You can read more about [Trinkets Updated on it's Modrinth page!](https://modrinth.com/mod/trinkets-updated)

For old Polymer Port repo (Trinkets <=3.11.0-beta.1), go to https://github.com/PolymerPorts/trinkets

For development purposes, you need to depend on Trinkets Updated, with this being added as an
additional jar.
